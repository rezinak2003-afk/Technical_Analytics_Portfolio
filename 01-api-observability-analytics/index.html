Project overview

An interactive observability dashboard using a realistic, deterministic synthetic API telemetry dataset. Explore request volume, error rates, latency percentiles, endpoint health, and hourly trends.

  • KPI cards for requests, error rate, p95 latency, and availability
  • Interactive time-range and endpoint filters
  • Latency and request-volume trend charts
  • Endpoint-level reliability table
  • Synthetic data generator included in JavaScript

Data & methodology

This is a portfolio demonstration, not live production telemetry. All values are synthetic and generated locally in the browser.

Reproducibility: the dashboard generates deterministic demo records in the browser. Filters and charts work without API keys, paid services, or a server.

Suggested next step: replace the synthetic generator with a validated real dataset and document the data source before using this as evidence of real-world findings.

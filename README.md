# Technical Analytics Portfolio — GitHub Ready

This package contains three self-contained static dashboards, with a portfolio landing page. No Python environment, Docker, API keys, or server are needed to publish the demos.

## Projects
1. API Observability Analytics
2. IoT Sensor Time-Series Analytics
3. Distributed Trace Critical-Path Profiler

## Publish all projects in one GitHub Pages site
Create a public repository, upload all files and folders from this package to the repository root, then go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**. The root `index.html` links to all three demos.

## Publish separately
Create a separate repository for each project and upload the contents of that project's folder to the repository root. Enable GitHub Pages with the same Settings path.

## Note
The dashboards use deterministic synthetic data to demonstrate working interactions and analytics UI. They are not connected to real production systems. Replace or supplement synthetic data with a documented real dataset before making real-world claims.
